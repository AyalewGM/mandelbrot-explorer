# Mandelbrot Set Explorer

**An infinite world of detail, born from one simple equation.**

This repository is an interactive explorer for the **Mandelbrot set**, one of the most recognizable objects in modern mathematics. The set was studied and popularized by mathematician **Benoit Mandelbrot** around 1980, building on earlier work in complex dynamics by **Gaston Julia** and **Pierre Fatou**. The application was originally part of [GLife](https://github.com/AyalewGM/GLife) and is now being developed independently in React.

## What is the Mandelbrot set?

The Mandelbrot set is a collection of points in the **complex plane**, where each point represents a complex number

$
c=a+bi, \quad i^2=-1.
$

For each candidate point $c$, start with $z_0=0$ and repeatedly calculate

$
\boxed{z_{n+1}=z_n^2+c.}
$

This process is called **iteration**. A point $c$ belongs to the Mandelbrot set precisely when the sequence $z_0,z_1,z_2,\ldots$ remains **bounded**—that is, it never escapes arbitrarily far from the origin.

For example:

- **$c=0$:** Every iterate is zero, so the point is in the set.
- **$c=-1$:** The sequence alternates $0,-1,0,-1,\ldots$, so this point is in the set.
- **$c=1$:** The sequence begins $0,1,2,5,26,\ldots$ and escapes, so this point is outside the set.

### How does the computer draw it?

For each pixel, the program maps its position to a complex number $c$. It repeatedly applies $z \leftarrow z^2+c$ and watches the magnitude $|z|$.

If $|z|>2$ at any step, the orbit will escape to infinity, so the point is **outside** the Mandelbrot set. The number of iterations before escape can be used to choose a color.

If the point **has not escaped after the selected maximum number of iterations**, the renderer typically colors it black. **This does not prove membership**: an orbit might escape later. Higher iteration limits provide more reliable pictures, especially near the intricate boundary.

The displayed colors are visualization choices, not intrinsic colors of the mathematical set.

## Why is the boundary so fascinating?

The Mandelbrot set has a recognizable central cardioid-like region and many attached bulb-shaped regions. Zoom near its boundary and you encounter spirals, filaments, repeated motifs, and endlessly new structures.

The **boundary is fractal**: detail keeps appearing at smaller scales. Although the set lies in a two-dimensional plane, its boundary has **Hausdorff dimension 2**, an astonishing result proven by Mitsuhiro Shishikura.

The set also connects to **Julia sets**, another family of complex dynamical objects. Changing the parameter $c$ changes the Julia set generated by the same quadratic iteration. The Mandelbrot set acts as a map of how those systems behave.

## Why is it still important?

**1. Chaos and dynamical systems.** The Mandelbrot set is a gateway to understanding how repeated nonlinear operations can create highly intricate behavior. It helps us study stability, parameter changes, and long-term dynamics.

**2. Complex numbers become visible.** It offers a visual reason to learn complex arithmetic and see how algebraic operations correspond to geometric structures.

**3. Fractal geometry.** Fractals challenge ordinary ideas of smoothness, scale, and dimension. Related mathematical techniques matter in the study of irregular shapes and structures in nature, scientific modeling, and signal analysis.

**4. Numerical computation.** Drawing the set teaches iteration, algorithms, numerical precision, rendering performance, and the limits of computer approximations. Deep zooming eventually requires higher-precision arithmetic than ordinary floating-point numbers provide.

**5. Art and mathematical beauty.** The Mandelbrot set demonstrates how strict mathematical definitions can produce extraordinary imagery. Color palettes make complex dynamics accessible through digital art.

**6. Mathematical research.** Complex dynamics remains an active field. The Mandelbrot set raises deep questions about geometry, topology, and the behavior of nonlinear systems.

## Running the application

The standalone React/TypeScript migration is under review in [PR #1](https://github.com/AyalewGM/mandelbrot-explorer/pull/1). On that branch:

```bash
npm install
npm run dev
npm test
npm run build
```

Click the image to zoom in, drag to select a region, and use the zoom buttons to navigate. Change the iteration limit and palette to explore how the same mathematical set can be visualized differently.
